Bookmark Sync

Two-way bookmark sync across Chrome, Edge, Brave, Firefox and Safari — stored in your own private GitHub repo. No account, no server, no iCloud for Windows.

Chrome · Edge · Brave

Windows and macOS

  1. Download and unzip.
  2. Open chrome://extensions and turn on Developer mode.
  3. Load unpacked → pick the unzipped folder.

Safari

macOS · also reaches iPhone and iPad via iCloud

  1. Install Node.js.
  2. Download and unzip, then in Terminal run bash mac/install.sh from the unzipped folder.
  3. Follow the three steps it prints.
Download for Mac

Firefox

Windows and macOS

  1. Download and unzip.
  2. Open about:debugging#/runtime/this-firefox.
  3. Load Temporary Add-on → pick manifest.json.
Download add-on
Why Safari is a Mac helper, not an extension. Safari is the only major browser with no bookmarks extension API, so no Safari extension can read or write a bookmark. The helper edits Safari's bookmark file directly instead — and iCloud carries those changes to your iPhone and iPad for free.

Before you start

Create an empty private GitHub repo for your bookmarks, then a fine-grained token with access to only that repo and Contents: Read and write. Paste it into each browser's extension options. Export a bookmarks backup from every browser before the first sync.
